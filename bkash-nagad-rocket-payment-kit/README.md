# bKash · Nagad · Rocket — Send-Money Checkout — renamed

This kit is now
[**bKash · Nagad · Rocket · Bank — Send-Money Checkout**](../bkash-nagad-rocket-bank-payment-kit/).

Nothing was removed and nothing was rebuilt — it grew a **fourth payment
method**, so the folder name grew one too. The three wallets work exactly as
they did.

What bank transfer adds, for merchants who take one:

- a **bank tile** in the method picker, beside the three wallets;
- the **full receiving account** in the popup — bank, account holder, account
  number, and branch and routing number when they are set — with **one tap that
  copies every row, labels included**, ready to paste into a banking app;
- a reference field that takes **what banks actually print** (4–40 characters,
  `A-Z 0-9 / -`) instead of forcing a phone number;
- the same wallet tabs, refresh-proof popup and Facebook-in-app-browser
  keyboard kit as before.

Bank is optional. Leave the bank details out of the config and the kit is the
three-wallet checkout you already know.
